# Photon64 v1.0.0-preview.1

Photon64 is an experimental Nintendo 64 emulator bundled into one self-contained HTML app: a C/WebAssembly core, WebGPU rendering with a software fallback, and a local cartridge library.

## Download and play

Download **photon64.html** from the assets below and open it in a modern browser with WebAssembly SIMD support. Add your own cartridge dump or ZIP. Commercial games are not included.

If local-file GPU or storage access is restricted, serve the file from localhost. Back up battery saves before upgrading: save states are tied to the core build and may be rejected after changes.

## Included in this preview

- Improved renderer coverage and independent raw-framebuffer/VI validation.
- Local game library, battery saves, four state slots, keyboard/gamepad/touch controls and configurable picture settings.
- Clean SVG branding, responsive menus, compact save slots for short screens, safe-area spacing and corrected high-DPI presentation proportions.
- Keyboard focus and dialog navigation, Safari focus restoration, touch-input release and fullscreen failure handling.
